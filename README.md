# NET1014 Campus Network Design

## Overview

This project was completed for the Networking Principles (NET1014) course.

The objective was to design and implement a campus network using Cisco Packet Tracer, connecting multiple laboratories and university buildings while applying fundamental networking concepts.

## Features

- Campus network topology
- Router and switch configuration
- IPv4 addressing
- Subnetting
- Inter-building connectivity
- Physical and logical topology design

## Tools Used

- Cisco Packet Tracer

## Repository Contents

- `Campus-Network-Topology.pkt` – Cisco Packet Tracer project
- `Project-Report-Networking-Principles.pdf` – Project documentation and network design report
